# My Library
A web application made for The Odin Project's [Library project](https://www.theodinproject.com/lessons/node-path-javascript-library).

## How to use
Click **add book** and input the title, author, page count, and check whether or not you've read it. You can edit the information on books, and you can also just trash them.

## Modding
The web app is very easy to mod in both style and script. I made an effort to organize the code in a way that is very human-readable. You can absolutely make custom themes and new features.
